# Volt Prime — Site demonstrativo

Projeto fictício de portfólio criado com React, TypeScript, Vite e Tailwind CSS.

## Como executar
1. Instale Node.js (versão LTS).
2. Abra um terminal nesta pasta.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra o endereço local mostrado pelo Vite.

## Build de produção
Execute `npm run build`. O resultado será criado na pasta `dist`.

## Importante
A Volt Prime é uma marca fictícia. Os preços, experiência, horários, garantias e área de atendimento são demonstrativos. Os botões de orçamento apenas exibem um aviso e não enviam mensagens nem representam um contato real. Antes de adaptar o projeto para uma empresa verdadeira, substitua e confirme todos os dados, contatos, preços e condições.
